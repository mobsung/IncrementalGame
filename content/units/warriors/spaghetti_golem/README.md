# Spaghetti Golem — Rare Warrior

- `forms/`: Noodle Squire (base), Saucebound Knight (level 10), Spaghetti Golem (level 25).
- `abilities/`: Meatball Jab/Sweep, Slow Simmer, Sauce Reserve, Sauce Guard and Glassheart Surge; species runtime lives in `spaghetti_kit.gd`.
- `upgrades/`: Sauce Infusion, Meatball Training, Thickened Glaze and Core Tempering.
- `visuals/`: current sprites and presentation resources; see ART_NOTES.md.
- `visuals/animations/`: procedural motion for all forms, effects and isolated F6 preview.
- `gacha/spaghetti_rare.tres`: summon entry, always the base form.
- `concepts/`: original sheets and detailed user concept.
- `design/`: previous John specification, retained as history only.

Old `john_*`, `spaghetti_sweep.tres`, and the six previous upgrade resources are historical and no longer referenced by the arena or summon pool. Implementation details: `docs/implementation/SPAGHETTI_GOLEM.md`.
